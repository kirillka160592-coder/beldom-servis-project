# Перенос сайта на Beget (обычный хостинг, PHP + MySQL)

Эта папка — автономный комплект для запуска сайта на вашем хостинге Beget,
независимо от poehali.dev. Здесь всё, что нужно: backend на PHP, дамп базы
для MySQL и адаптированный файл api.ts для фронтенда.

## Что внутри

- `api/` — 4 PHP-скрипта (замена Python Cloud Functions) + config.php
- `sql/dump.sql` — структура таблиц + все текущие данные (новости, тексты сайта, админ)
- `api-ts-for-beget/api.ts` — замена файла `src/lib/api.ts` во фронтенде

## Шаг 1. Создайте базу данных MySQL

1. В панели Beget: **Базы данных → MySQL → Добавить базу**
2. Запишите: имя базы, имя пользователя, пароль, хост (обычно `localhost`)
3. Откройте **phpMyAdmin** для этой базы → вкладка **Импорт** → выберите файл `sql/dump.sql` → **Ok**
4. Проверьте, что появились 4 таблицы: `admin_users`, `admin_sessions`, `content_blocks`, `news`, `media_library`

## Шаг 2. Настройте config.php

Откройте `api/config.php` и впишите свои данные из шага 1:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'ваша_база');
define('DB_USER', 'ваш_пользователь');
define('DB_PASS', 'ваш_пароль');
define('UPLOAD_URL', 'https://ваш-домен.ru/uploads');
```

## Шаг 3. Загрузите файлы на хостинг

Через FTP или файловый менеджер Beget:

1. Создайте в корне сайта (`public_html` или аналог) папку `api`
2. Загрузите туда всё содержимое папки `api/` (все `.php` файлы + `.htaccess`)
3. Создайте рядом папку `uploads` (для новых картинок и документов из админки) и дайте ей права на запись (755 или 775)

## Шаг 4. Соберите и загрузите фронтенд

1. В poehali.dev нажмите **Скачать → Скачать билд** — получите готовые HTML/CSS/JS файлы
2. **Важно:** этот билд ещё обращается к старому poehali.dev backend. Чтобы переключить его
   на новый PHP backend, нужно до сборки билда заменить файл `src/lib/api.ts` на файл
   `api-ts-for-beget/api.ts` из этого комплекта — тогда сайт будет ходить в `/api/*.php`
3. Загрузите содержимое билда в корень сайта на Beget (`public_html`), туда же, где лежит папка `api`
4. Скопируйте файл `htaccess-root/.htaccess` из этого комплекта тоже в корень сайта
   (`public_html`, рядом с `index.html`). Без него прямой переход по ссылке вида
   `/admin/news` (например, обновление страницы или переход по прямой ссылке) будет
   выдавать ошибку `404 Not Found` от Apache — сайт открывается только с главной страницы

## Шаг 5. Проверьте работу

1. Откройте ваш домен — сайт должен открыться, новости и тексты — подгрузиться из новой базы
2. Зайдите в `/admin` → войдите под логином **admin** (пароль — тот же, что был на poehali.dev)
3. Попробуйте отредактировать новость и загрузить фото — если файл сохранился в папке `uploads` и появился на сайте, всё настроено верно

## Важные ограничения после переезда

- **Фото в старых новостях** ссылаются на `cdn.poehali.dev` — они продолжат открываться,
  но зависят от чужого облака. Если хотите полной независимости — перезалейте эти
  картинки через новую админку и замените ссылки.
- **Формат хранения файлов** изменился: раньше файлы уходили в S3-хранилище poehali.dev,
  теперь — сохраняются прямо в папку `uploads` на вашем хостинге. Регулярно делайте
  резервную копию этой папки и базы данных через панель Beget.
- Пароль администратора хранится в том же зашифрованном виде — логин и пароль от
  входа в `/admin` останутся прежними.

## Если что-то не работает

- Ошибка `500` при открытии `.php` файла — проверьте данные в `config.php` и включён ли PDO MySQL
  в панели Beget (обычно включён по умолчанию)
- Форма входа в админку не работает — откройте консоль браузера (F12 → Network),
  проверьте, что запрос идёт на `/api/admin-auth.php`, а не на poehali.dev
- Изображения не сохраняются — проверьте права на папку `uploads` (должна быть доступна на запись)
